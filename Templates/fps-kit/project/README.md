# Classic FPS Kit

Make a Doom-style game by dragging prefabs onto a map.

**To start:** press **P** to play the example game, then open a level from `Assets/Levels` and read the
yellow comment pins on its map. To build your own level, duplicate **Blank Base Level**.

The step-by-step guide starts at `docs/wiki/guide/README.md` in the engine's documentation.

| Folder | What's inside |
|---|---|
| `Assets/Levels` | Main Menu, four example levels, Blank Base Level and Prefab Gallery |
| `Assets/Prefabs` | Everything you can drag into a level |
| `Assets/UI Layouts` | The HUD, menus and the screen between levels |
| `Assets/Textures`, `Sprites`, `Animations`, `Sounds` | Art and sound |
| `Assets/Scripts` | The few things that needed code, each explained in comments |
| `Assets/Music` | A track for the menu and each example level, with `CREDITS.txt` |
| `Assets/Freedoom` | The art's licence. Keep it with your game. |

Art and sound are from [Freedoom](https://freedoom.github.io/), under a BSD licence. The music is CC0, from
[OpenGameArt](https://opengameart.org/).

The menu lettering in `Assets/UI/Words`, the numbers in `Assets/UI/Digits/Tally *` and `Assets/Fonts/Classic HUD.ttf` were drawn for this kit, not taken from Freedoom. Use them however you like.
